# Grapeee Runtime API Draft

## Health

`GET /health`

```json
{
  "ok": true,
  "version": "0.1.0",
  "studioConnected": true
}
```

## Current Session

`GET /sessions/current`

Returns the active Studio/plugin/runtime session.

## Studio Tree

`GET /studio/tree`

Returns a compact Roblox tree:

```json
{
  "root": "game",
  "children": [],
  "selection": []
}
```

## Apply Operations

`POST /operations/apply`

Accepts structured operations generated by the model/control plane.

```json
{
  "snapshotBeforeApply": true,
  "operations": [
    {
      "kind": "create_script",
      "target": "ServerScriptService/SwordShop.server.lua",
      "value": "print('hello')"
    }
  ]
}
```

## Rollback

`POST /snapshots/{id}/rollback`

Restores the pre-apply state for a prompt iteration.
